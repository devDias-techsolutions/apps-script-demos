# SSMA Workspace — Portfolio Demo

Dashboard demonstrativo de **Segurança, Saúde e Meio Ambiente (SSMA)** para pequenas e médias empresas.

## O que a demo demonstra

- Dashboard de conformidade
- Indicadores de treinamentos e exames
- Controle de vencimentos
- Visão por unidade/setor
- Fichas e controles de EPI
- Estrutura preparada para colaboradores, documentos e auditoria
- Interface responsiva
- Visualização de indicadores com SVG/JavaScript

## Stack / conceito

- Google Apps Script
- Google Workspace / Google Sheets como camada de dados no conceito original
- HTML5
- CSS3
- JavaScript

## Dados

Todos os nomes, números, setores e registros apresentados são fictícios e foram criados exclusivamente para portfólio.

## Observação

Esta pasta contém uma **edição pública de demonstração**, sanitizada para portfólio. Ela não utiliza dados, credenciais ou endpoints corporativos reais.
