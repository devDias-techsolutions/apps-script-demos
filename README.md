# DevDias Tech Solutions — Apps Script Demos

Coleção pública de demonstrações de aplicações web desenvolvidas com **Google Apps Script, Google Workspace, HTML, CSS e JavaScript**.

## Objetivo

Apresentar, de forma prática, como processos de pequenas e médias empresas podem ser transformados em aplicações web sob medida, utilizando o ecossistema Google como base.

## Sobre os dados

Todos os nomes de empresas, colaboradores, indicadores, documentos, registros e demais informações presentes nas demos são **fictícios** e existem exclusivamente para demonstração.

Nenhum dado corporativo ou pessoal real deve ser utilizado como referência de produção.
